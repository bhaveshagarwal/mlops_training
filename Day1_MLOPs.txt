Specific branch : ML Machine Learning - subset of AI
                  - enables systems to learn patterns from historical data (datasets - huge - csv)
                  - ML and then it uses patterns to make predictions or decisions on new data
                  - training a ML model

                   Historical Information of House Prices

                   10000 records
                   - Location Area     Bedrooms OpenArea  Price
                   - 110078   C1 Block   4        30%      2Cr
                 
                   Dataset : collection of observations used for ML model
                   Features : Input variables - help algorithm identify patterns - Location Area Bedrooms OpenArea
                   Target Variable : Price - value we want to predict
                   Training Data : portion of dataset used to teach the algorithm (80% of the dataset)
                   Testing Data : separate portion of dataset - evaluate how well the trained model performs on unseen obs (20%)
                   Model : learned mathematical representation produced after training ML algorithm
                         : captures patterns from the data
                         : uses those patterns to generate predictions

                   New set of values : 565757 B 5 25% -> Price? (AI ML model - tell you - predict the price)
                    
                   Two Types : Supervised ML 
                               - historical dataset - both inputs (features) and outputs (target) are known
                               Algorithms 
                               - Linear Regression, Logistic Regression, Decision Trees, Random Forest, SVM
                           
                             : Unsupervised ML
                               - historical dataset - inputs (features) are known
                               - retail company - group customers according to purchasing behaviour
                               - Cust Name, Location, Contact No, Amount, Payment Method, Points
                               - K-Means Clustering, KNN (K Nearest Neighbours)
